# پرتفولیوی سینا پیرزاده

صفحه‌ی شخصی و معرفی (پرتفولیو) با طراحی خلاقانه و افکت‌های سه‌بعدی مبتنی بر CSS، ساخته‌شده با Next.js و Tailwind CSS.

🔗 دمو: به‌زودی
📄 رزومه: [دانلود PDF](https://github.com/pirroot/pirroot/blob/main/resume.pdf)

## ویژگی‌ها

- طراحی با تم ترمینال/کد، رنگ‌بندی طلایی و سبز نعنایی روی پس‌زمینه‌ی تیره
- پنجره‌ی کد شناور با افکت سه‌بعدی (perspective / rotateX / rotateY) — فقط با CSS خالص، بدون جاوااسکریپت
- کارت‌های پروژه با چرخش سه‌بعدی هنگام هاور
- ریسپانسیو کامل و پشتیبانی از `prefers-reduced-motion`
- راست‌به‌چپ (RTL) و فونت فارسی Vazirmatn + مونو JetBrains Mono برای بخش‌های کد
- کامپوننت کاملاً سروری (بدون `use client`) برای SEO و رندر سریع
- متادیتای کامل SEO (title، description، keywords، Open Graph) + Schema.org (`Person`) به‌صورت JSON-LD

## پیش‌نیازها

- Node.js نسخه ۱۸ یا بالاتر
- یک پروژه‌ی Next.js (App Router) با Tailwind CSS از قبل نصب‌شده

اگر پروژه‌ای از قبل نداری:

```bash
npx create-next-app@latest my-portfolio --typescript --tailwind --app
cd my-portfolio
```

## نصب و اجرا

```bash
npm install
npm run dev
```

سپس صفحه در آدرس زیر در دسترس است:

```
http://localhost:3000
```

## ساختار پروژه

```
.
├── app/
│   └── page.tsx      # صفحه‌ی اصلی پرتفولیو (سروری، بدون use client)
├── public/            # فایل‌های استاتیک (در صورت نیاز به تصاویر یا رزومه)
└── README.md
```

فقط کافی است فایل `page.tsx` را در مسیر `app/page.tsx` پروژه‌ی خودت قرار دهی؛ فایل کاملاً خودکفا (self-contained) است و به کتابخانه‌ی جانبی‌ای جز `next/font/google` (که خود Next.js فراهم می‌کند) نیاز ندارد.

## شخصی‌سازی

برای ویرایش اطلاعات، بخش‌های زیر در بالای `page.tsx` را تغییر بده:

| متغیر        | محتوا                                              |
| ------------ | -------------------------------------------------- |
| `stack`      | لیست تکنولوژی‌های نمایش‌داده‌شده در هرو            |
| `experience` | سوابق کاری (شرکت، نقش، بازه‌ی زمانی، توضیح، تگ‌ها) |
| `projects`   | پروژه‌ها (عنوان، توضیح، لینک، استک)                |
| `contacts`   | شماره تماس و ایمیل                                 |
| `socials`    | شبکه‌های اجتماعی                                   |
| `jsonLd`     | داده‌ی ساختاریافته برای موتورهای جستجو             |

رنگ‌های اصلی به‌صورت مقادیر دلخواه (arbitrary values) تایلویند در همان کلاس‌ها نوشته شده‌اند:

- پس‌زمینه: `#0B1210`
- سطح/کارت: `#121C19`
- طلایی (رنگ اصلی): `#E9B44C`
- سبز نعنایی (رنگ ثانویه): `#7FDBB6`
- متن اصلی: `#EDF3EF`
- متن کم‌رنگ: `#7C948B`

برای تغییر پالت رنگی، همین مقادیر هگز را در فایل جستجو و جایگزین کن.
